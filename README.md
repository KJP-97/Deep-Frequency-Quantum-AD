# Deep-Frequency-Quantum-AD
This repository presents a hybrid deep-frequency quantum framework for explainable Alzheimer’s disease detection using MRI images. The framework integrates deep, radiomic, frequency-domain, and texture features to provide a comprehensive representation of Alzheimer’s-related patterns.

The proposed approach combines EfficientNet-B4, Vision Mamba, Adaptive Quantum Binary Particle Swarm Optimization (AQBPSO), Variational Quantum Classification (VQC), and Attention Fusion for feature extraction, optimization, and classification. Eigen-CAM is incorporated to provide explainable visual interpretations of the model predictions.

The repository contains the implementation, experimental configurations, evaluation scripts, and supporting resources required to reproduce the proposed framework and its experimental analysis.
